Apriori-Window MD
空間開始ベクトルごとの時間区間列

apriori_window_md/src/md_apriori.rs の現行実装は、 多次元でも dense cell 集合を返さない。 各 spatial_start = (s_1, ..., s_{d-1}) に対して [(t_start, t_end), ...] を返す interval-based 実装である。

1. 主題

d 次元化しても、時間軸だけは特別扱いする。空間開始ベクトルを 1 つ固定すると、 問題は「重複時刻を許す 1D Apriori-Window」に還元される。

入力
(t, x_1, ..., x_{d-1}, items)
固定するもの
spatial_start = (s_1, ..., s_{d-1})
出力
spatial_start -> [(t_start, t_end), ...]

2. 3D 箱庭を 1D へ潰す

3D の小例で、Wt=2, Wx=2, Wy=2, θ=2 とする。

t(x,y)=(0,0)(1,0)(0,1)(1,1)
0{A,B}{A}––
1––{A,B}{B}
2–{A,B}––

spatial_start = (0,0) のとき

空間窓は x=[0,1], y=[0,1]。パターン A の出現は L_A((0,0)) = [0, 0, 1, 2] へ潰れる。 ここでも t=0 が 2 回あるのは、別セルの出現が同じ空間窓へ入っているから。

t = 0
(0,0):{A,B} (1,0):{A}
t = 1
(0,1):{A,B} (1,1):{B}
t = 2
(1,0):{A,B}
t = 3
–

3. 実行トレース

上の L_A((0,0)) = [0,0,1,2] に対して、1D の duplicate-aware interval solver を適用する。

step l window count dense_end / next_outside action emit next l
1 0 [0,1] 3 dense_end = 0, block_rightmost = 1 dense block [0,0] を一括処理 — 1
2 1 [1,2] 2 dense_end = 1, block_rightmost = 2 dense block [1,1] を追加し、rightmost を 2 へ伸ばす — 2
3 2 [2,3] 1 next_outside = none count < θ なので現在の dense interval を閉じる [0,2] stop

したがって spatial_start=(0,0) では A -> [(0,2)] を得る。

4. d 次元への一般化

2D との違いは、空間開始点がスカラーではなくベクトルになることだけである。

for each pattern P:
  for each spatial_start = (s_1, ..., s_{d-1}):
    L_P(spatial_start) = times inside the spatial window
    solve duplicate-aware 1D dense intervals on L_P(spatial_start)
  store:
    DenseRegion { spatial_start, intervals }

Apriori 枝刈り

候補パターン P では、各 singleton item の spatial_start -> intervals を、同じ spatial_start ごとに交差する。 その候補区間だけを exact に再評価するので、3D でも ND でも 1D と同じ interval intersection 型の枝刈りになる。
