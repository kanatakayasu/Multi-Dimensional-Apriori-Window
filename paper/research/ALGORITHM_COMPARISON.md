# アルゴリズム比較メモ：本論文 vs 高橋論文（Apriori-Window 原著）

> 作成日: 2026-04-10
> 対象: `paper/DSAA2026/sec/04_proposed_method.tex` の Algorithm 1（t軸ストライド）
> 比較対象: `paper/takahasi.pdf`（高橋論文）の Algorithm 1（Scan）

---

## 結論

`Wx = Wy = 1`（1次元）とした場合、両アルゴリズムが出力する**密集ウィンドウ開始点の集合は等価**。
ただし以下の2点で実装が異なる。どちらも**正確性には問題ない**が、一方は非効率、もう一方は記述に誤解の余地がある。

---

## 差異①：c = θ（サポートが閾値ちょうど）のときのジャンプ

### 高橋論文（Algorithm 1, line 20）

```
surplus ← cnt − σ      # surplus = 0
l_next ← occ[idx_start + surplus] + 1
        = occ[idx_start] + 1
        = L[l_lo] + 1    # ウィンドウ内最左出現の1つ先
l ← l_next
```

`surplus = 0` でも surplus > 0 と同じ式を使い、**L[l_lo] + 1 まで一気にジャンプ**。
命題3より区間 `[l, L[l_lo]]` は全て密集。スキップして区間右端 e を更新。

### 本論文（Algorithm 1, `else` 分岐）

```
l ← l + 1
```

c = θ を `else` ブランチで別処理し、**1ずつ進む**。

### 影響

`L[l_lo] > l` の場合（ウィンドウ左端に出現がない場合）、本論文は `l+1, l+2, …` と1ステップずつ確認するが、高橋論文は `L[l_lo]+1` まで一気にスキップする。

**出力の差異**: なし（同じ開始点集合を出力）
**効率の差異**: あり（本論文は c = θ 時に非効率）

### 修正案

```
% 現状（c = θ のとき非効率）
if c > θ:
    l ← max(l+1, L[l_lo + (c−θ)])
else:          % c = θ
    l ← l + 1

% 修正案（c = θ も統一して高橋論文と一致）
l ← max(l+1, L[l_lo + (c−θ)] + 1)
% surplus=0 のとき → max(l+1, L[l_lo]+1)
% surplus>0 のとき → max(l+1, L[l_lo+surplus]+1)
```

## 差異②：c > θ のストライドジャンプ先が1ずれる

### 高橋論文

```
l_next = occ[idx_start + surplus] + 1   # surplus 番目出現の「1つ先」へ
```

### 本論文（式 eq:jump_dense）

```
l ← max(l+1, L[l_lo + (c−θ)])          # surplus 番目出現「そのもの」へ
```

高橋論文は `L[l_lo + surplus] + 1` にジャンプし、区間 `[l, L[l_lo+surplus]]` を全てスキップ。
本論文は `L[l_lo + surplus]` 自体にジャンプし、次のイテレーションでその位置を明示評価 + prev による補填を行う。

**出力の差異**: なし（本論文は L[l_lo+surplus] を次イテレーションで明示確認後に補填するため）
**効率の差異**: わずかにあり（1回分余分にイテレーションする）
**記述の問題**: 論文の説明文「surplus 番目のイベントの時刻へジャンプ」は正しいが、高橋論文の命題3（「surplus 番目の1つ先まで全て密集」）との対応が分かりにくい。

### 修正案

差異①の修正案（`+1` 統一）を採用すれば差異②も同時に解消される。

---

## 差異③：密集区間開始時の「戻り」

### 高橋論文

初めて密集窓 `l*` を発見したとき、密集区間左端を次のように「戻す」：

```
s ← max(T_min, t_σ − W)
```

`t_σ` は `[l*, l*+W]` 内の σ 番目の出現。`t_σ − W < l*` になり得るため、左端が l* より前に確定される。

### 本論文

`L[0] − (W_t − 1)` という**十分早い位置からスキャン開始**するため、戻り不要。
最初の密集開始点（`t_σ − W`）は必ず `L[0] − (W_t − 1)` 以降にあるため、スキャン中に自然に到達する。

**出力の差異**: なし
**設計の優劣**: 本論文の方がシンプル（高橋論文は候補区間 cand で開始位置が制限されているため戻りが必要になる）

## 出力形式の違い（等価性の確認）

| | 出力 |
|---|---|
| 高橋論文 | 密集区間 `[s, e]` を直接構築 |
| 本論文 | 密集開始点集合 S → Union-Find 連結成分 |

1次元の連結成分 = `[min(S), max(S) + W_t − 1]` = 高橋論文の `[s, e]`。等価。

## 参考：高橋論文の命題3（ストライドスキップの安全性）

> 窓 `[l, l+W]` において surplus = sup(P,l,W) − σ ≥ 0 のとき，
> `l ≤ l' ≤ occ[idx_start + surplus]` を満たす任意の l' に対し，
> `[l', l'+W]` も密集窓である。
> ゆえに，l を `occ[idx_start + surplus] + 1` まで前進させても密集区間を見落とさない。

本論文の補題2（ストライドの正確性）は同一内容の d 次元版。
